# Проверка игры

Проверено 13 сентября 2026 года.

- **24 автоматических теста пройдены**: начисление +1/−1, отрицательный рейтинг, повторные нажатия, тайм-аут, пауза, тренировка, завершение смены, воспроизводимость и баланс очереди, корректность сценариев и источников, безопасная раздача файлов сервером.
- В браузере пройдена полная тренировка из 12 клиентов: 11 верных ответов, 1 ошибка, итог **10 очков**, **92%**, лучшая серия **11**. Разбор ошибки соответствует запросу клиента.
- Проверены справочник после ответа и возврат к следующему клиенту, перезапуск, переключение режимов, ручная пауза и штраф за истечение 35 секунд.
- Проверено представление 390 × 844: горизонтальной прокрутки нет, все шесть кнопок доступны, высота каждой — 70 px. После ответа интерфейс прокручивается к объяснению. Это проверка адаптивной вёрстки в Chromium, а не испытание на физических iPhone/Android.
- Автономный HTML проверен через локальный HTTP: Python запускается, правильный талон даёт +1. Все игровые ресурсы встроены. Проверяющий браузер блокирует навигацию по `file://`, поэтому прямой запуск двойным щелчком этим инструментом не проверялся.
- **Офлайн-проверка PWA пройдена**: после заполнения кэша `osm-game-v4` сеть вкладки отключена, страница перезагружена, смена начата и правильный талон выдан (+1). Затем сеть восстановлена. Кэш требует HTTPS или localhost; для HTTP-адреса компьютера в Wi-Fi это свойство не заявляется.
- Оба CMD проверены с `--help`. Сборка создаёт автономный HTML ~1,3 МБ и ZIP ~550 КБ, включая исходники, тесты и лицензию Brython.

Основная команда повторной проверки:

```powershell
py -3 -m unittest discover -s tests -v
```

## Android 1.0.0 — подписанный выпуск

Проверено 13 сентября 2026 года. Сборка исходников `7c7c42f797f5ada23b15e7b620bb69c6c7fd45a1`. [Успешный запуск GitHub Actions](https://github.com/peter20191233/osm-manager-game/actions/runs/34756643411).

- На эмуляторах **Android 12 / API 31** и **Android 15 / API 35** подписанный release APK прошёл по **3 инструментальных теста**, без ошибок. Wi-Fi и мобильные данные отключены до установки и первого запуска.
- Проверены встроенные Python/Brython и иллюстрация, настоящие касания начала игры и первого талона, полная тренировка из 12 клиентов (2 верных ответа, 10 неверных, рейтинг −8), защита от повторного начисления и сохранение рекорда после перезапуска.
- Уход приложения в фон сохраняет текущего клиента и останавливает таймер; после возврата можно продолжить смену.
- `apksigner` проверил подпись приложения и тестового APK. Тест внутри установленного приложения подтвердил отсутствие флага `debuggable`, публичный отпечаток сертификата и SHA-256 самого установленного APK. Тестовое приложение распространяемому APK не требуется и в него не включено; отладка WebView для этих проверок не включалась.
- У игры нет разрешения `INTERNET` и встроенных нативных `.so`; все игровые ресурсы находятся внутри APK. Один файл подходит для разных архитектур процессора.
- Размер выпускаемого файла — **309,559 байт** (около 300 КиБ). Содержимое всех файлов APK из двух проверенных сборок совпадает; SHA-256 опубликованного файла указан ниже.
- Кнопка скачивания на сайте проверена при ширине 390 px: текст помещается, горизонтальной прокрутки нет, высота кнопки — 44,4 px.
- Физические телефоны не проверялись.
