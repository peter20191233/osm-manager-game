# Проверка игры

Проверено 13 сентября 2026 года.

- **24 автоматических теста пройдены**: начисление +1/−1, отрицательный рейтинг, повторные нажатия, тайм-аут, пауза, тренировка, завершение смены, воспроизводимость и баланс очереди, корректность сценариев и источников, безопасная раздача файлов сервером.
- В браузере пройдена полная тренировка из 12 клиентов: 11 верных ответов, 1 ошибка, итог **10 очков**, **92%**, лучшая серия **11**. Разбор ошибки соответствует запросу клиента.
- Проверены справочник после ответа и возврат к следующему клиенту, перезапуск, переключение режимов, ручная пауза и штраф за истечение 35 секунд.
- Проверено представление 390 × 844: горизонтальной прокрутки нет, все шесть кнопок доступны, высота каждой — 70 px. После ответа интерфейс прокручивается к объяснению. Это проверка адаптивной вёрстки в Chromium, а не испытание на физических iPhone/Android.
- Автономный HTML проверен через локальный HTTP: Python запускается, правильный талон даёт +1. Все игровые ресурсы встроены. Проверяющий браузер блокирует навигацию по `file://`, поэтому прямой запуск двойным щелчком этим инструментом не проверялся.
- **Офлайн-проверка PWA пройдена**: после заполнения кэша `osm-game-v4` сеть вкладки отключена, страница перезагружена, смена начата и правильный талон выдан (+1). Затем сеть восстановлена. Кэш требует HTTPS или localhost; для HTTP-адреса компьютера в Wi-Fi это свойство не заявляется.
- Оба CMD проверены с `--help`. Сборка создаёт автономный HTML ~1,3 МБ и ZIP ~550 КБ, включая исходники, тесты и лицензию Brython.

Основная команда повторной проверки:

```powershell
py -3 -m unittest discover -s tests -v
```
