# «Будни ОСМ» для Android

Android-версия игры «Будни Операционно-Сервисного Менеджера» устанавливается из одного APK. Небольшая Android-оболочка на Java открывает встроенную игру в системном WebView; игровая логика написана на Python и выполняется встроенной библиотекой Brython. Все игровые файлы и векторная графика входят в APK. Пользователю не нужны Python, архиватор, компьютер или дополнительные загрузки. Интернет нужен для первоначального скачивания APK; сама игра работает локально.

Версия приложения: **1.1.0** (`versionCode 2`). Минимальная версия системы: **Android 12 / API 31**. Идентификатор приложения: `ru.peterkorytov.osmgame`.

Размер APK: **947 735 байт**, примерно **0,95 МБ**. Выпуск подписан постоянным ключом и проверен на эмуляторах Android 12 и 15; результаты сохранены в [QA.md](QA.md).

В версии 1.1.0 добавлена встроенная музыка «Спокойная смена», сочинённая ИИ Codex. Она запускается с началом смены; кнопка **♪** управляет музыкой и звуками. При паузе или сворачивании музыка останавливается. [О музыке](MUSIC.md).

## Скачать и установить

**[Скачать osm-manager-game-android.apk с сайта](https://peter20191233.github.io/resume-site/downloads/osm-manager-game-android.apk)**

[Резервная ссылка на APK в GitHub Releases](https://github.com/peter20191233/osm-manager-game/releases/download/android-v1.1.0/osm-manager-game-android.apk) · [Страница выпуска на GitHub](https://github.com/peter20191233/osm-manager-game/releases/tag/android-v1.1.0)

1. Откройте ссылку на APK на Android-телефоне и дождитесь завершения скачивания.
2. Нажмите на скачанный **`osm-manager-game-android.apk`** в уведомлении браузера. Его также можно найти в приложении **«Файлы» → «Загрузки»**.
3. Если система сообщает, что этому источнику не разрешена установка приложений, откройте предложенные **«Настройки»** и разрешите установку только для приложения, из которого открыли файл — например, браузера или «Файлов». Вернитесь к APK. Названия пунктов зависят от производителя телефона. [Справка Android об установке вне Google Play](https://developer.android.com/distribute/marketing-tools/alternative-distribution).
4. Нажмите **«Установить»**, затем **«Открыть»**.
5. В игре выберите **«Начать смену →»** или тренировку без таймера.

В следующий раз запускайте игру значком **«Будни ОСМ»** в списке приложений. Открывать APK заново не нужно. Распаковывать его и открывать папки `assets`, `vendor` или Python-файлы не требуется.

Для обновления скачайте новый APK с этого же сайта или из GitHub Releases и установите его поверх текущей версии. Android принимает обновление с тем же идентификатором приложения и ключом подписи. APK предназначен для Android; на iPhone используйте браузерный вариант, описанный в [README.md](README.md).

## Сборка в GitHub Actions

Этот раздел нужен разработчику. Игрок скачивает готовый APK по ссылке выше.

1. В репозитории откройте **Actions → Android APK → Run workflow**.
2. Выберите ветку **`main`** и установите параметр **`signed_release=true`**.
3. Запустите workflow и дождитесь успешного завершения обеих проверок: **API 31** и **API 35**.

Подписанная сборка разрешена только для `main`. Workflow использует четыре секрета репозитория:

| Секрет GitHub Actions | Значение |
| --- | --- |
| `OSM_KEYSTORE_BASE64` | Хранилище ключа подписи, закодированное в Base64 |
| `OSM_KEYSTORE_PASSWORD` | Пароль хранилища |
| `OSM_KEY_ALIAS` | Имя ключа внутри хранилища |
| `OSM_KEY_PASSWORD` | Пароль ключа |

Секреты подписи настроены для этого репозитория. Workflow восстанавливает хранилище во временный файл на машине сборки, подписывает APK и удаляет временный файл после шага подписи. В результатах успешного запуска публикуются артефакты `android-build-api-31` и `android-build-api-35`: APK, отчёты и материалы проверки. Для распространения игрокам используйте находящийся внутри подписанный **`osm-manager-game-android.apk`**.

Публичный **SHA-256 сертификата подписи**:

```text
24280b33753e25bb2e90ae4af85d5862da25c44b72be76ddf86a534a58a16f7e
```

Workflow проверяет этот отпечаток при проверке подписанного выпуска. Контрольная сумма самого APK зависит от содержимого сборки и записывается отдельно в материалы проверки.

## Локальная сборка разработчиком

Этот раздел нужен только для изменения или самостоятельной сборки приложения. Игроку инструменты разработки не нужны.

Требуются:

- Python **3.10 или новее** для сборки автономной HTML-игры;
- **JDK 17**;
- **Gradle 8.11.1**;
- Android SDK: **Platform 35** и **Build Tools 35.0.0**;
- приватный ключ подписи для устанавливаемого release APK.

Проект Gradle находится в `android/` и использует Android Gradle Plugin **8.9.2**, `minSdk 31` и `targetSdk 35`. Gradle и Android SDK устанавливаются на машине сборки; игроку они не нужны. `JAVA_HOME` должен указывать на JDK, `ANDROID_HOME` — на Android SDK. Gradle должен быть доступен в `PATH`.

### Подготовить ресурсы

В корне репозитория:

```powershell
py -3 -m unittest discover -s tests -v
py -3 build_release.py
```

При использовании другой команды Python замените `py -3` на неё. Android-сборка использует актуальный автономный файл `dist/Играть.html`, поэтому после изменения игры сначала пересоберите HTML.

### Настроить подпись

Для подписи release-сборки задайте четыре переменные окружения:

| Переменная | Значение |
| --- | --- |
| `OSM_KEYSTORE_FILE` | Абсолютный путь к хранилищу ключей |
| `OSM_KEYSTORE_PASSWORD` | Пароль хранилища |
| `OSM_KEY_ALIAS` | Имя ключа внутри хранилища |
| `OSM_KEY_PASSWORD` | Пароль ключа |

Передавайте пароли через секреты среды сборки или локальное окружение. **Не помещайте приватный ключ, пароли или файлы с ними в Git, APK либо публичный выпуск.** Храните резервную копию ключа отдельно: обновления опубликованного приложения должны быть подписаны тем же ключом. Публичный отпечаток сертификата и контрольная сумма APK могут публиковаться вместе с выпуском; они не заменяют приватный ключ.

### Собрать APK

Из корня репозитория перейдите в Android-проект и выполните:

```powershell
Set-Location android
gradle --no-daemon :app:assembleRelease
```

При заданных переменных подписи итоговый файл:

```text
android/app/build/outputs/apk/release/osm-manager-game-android.apk
```

Без переменных подписи сборка создаёт `android/app/build/outputs/apk/release/app-release-unsigned.apk`. Этот файл не подписан и не подходит для установки игроком. Сначала его нужно подписать ключом выпуска; наличие неподписанного файла не означает, что устанавливаемый APK готов к публикации.

Перед публикацией проверьте подпись с помощью `apksigner` из Android SDK Build Tools и установите APK на Android-устройство или эмулятор. Проверьте Android 12 / API 31 и Android 15 / API 35: начало смены, выбор талонов, изменение рейтинга, тренировку, паузу и повторный запуск без сети. Зафиксируйте результаты проверки выпуска в `QA.md`.
