# Будни Операционно-Сервисного Менеджера

Небольшая мультяшная игра про сотрудника банковского офиса. Клиенты описывают свою задачу, а вы выбираете на терминале подходящий раздел и выдаёте талон. Правильный ответ приносит **+1 рейтинга**, ошибка — **−1**. Игра объясняет верный маршрут клиента.

Логика написана на **Python** и выполняется в браузере с помощью локальной библиотеки **Brython**. Графика векторная, без тяжёлых изображений, игровых движков и скачивания библиотек во время игры. На телефоне Python устанавливать не нужно. Нужен современный браузер с JavaScript; производительность зависит от браузера и устройства, отдельной видеокарты не требуется.

## Запуск на Windows

1. Откройте **`dist/Играть.html`** двойным щелчком. Игра запустится в браузере.
2. Если получили `osm-game.zip`, сначала распакуйте его и откройте **«Играть.html»** из распакованной папки.

Этот файл автономен: Python, сервер и интернет **не нужны**. Код Python, библиотека Brython, её лицензия и графика уже находятся внутри. Для передачи игры другому компьютеру достаточно одного файла «Играть.html». Размер автономной игры — примерно **1,3 МБ**, ZIP со всеми исходниками — около **550 КБ**.

## Дополнительный запуск через Python

Локальный сервер нужен для доступа с телефона по Wi-Fi и удобной работы с исходниками. Запустите **«Запустить игру.cmd»** двойным щелчком. Откроется браузер с игрой. Оставьте окно запуска открытым; для остановки нажмите в нём **Ctrl+C**.

CMD требует **Python 3.10 или новее**. Он проверяет команды `py -3`, `python`, затем локальный Python среды Codex, если такой установлен. Если Python отсутствует, установите его с [python.org](https://www.python.org/downloads/windows/) и включите **Add Python to PATH**. Игре не нужны пакеты pip.

Запуск из терминала в папке игры:

```powershell
py -3 launcher.py
py -3 launcher.py --port 8766
py -3 launcher.py --no-browser
```

Если используете команду `python` или полный путь к Python, замените ею `py -3`. По умолчанию игра доступна только на этом компьютере по адресу `http://127.0.0.1:8765/`. Исходный `index.html` требует HTTP для загрузки Python-модулей; для запуска двойным щелчком используйте именно собранный **«Играть.html»**.

## iPhone и Android: играть через домашний Wi-Fi

1. Подключите компьютер и телефон к одной Wi-Fi сети.
2. На компьютере дважды щёлкните **«Играть на телефоне.cmd»** в распакованной папке игры. Альтернатива из терминала: `py -3 launcher.py --lan`.
3. Откройте на телефоне адрес, напечатанный сервером, например `http://192.168.1.10:8765/`. При нескольких адресах используйте IPv4 вашей Wi-Fi сети.
4. Если Windows запросит доступ к сети, разрешите Python в **частной сети**. Если телефон не видит компьютер, проверьте, что сеть не гостевая и не изолирует устройства друг от друга.

В этом режиме компьютер должен оставаться включённым, а сервер — работать. Интернет после получения файлов игры не нужен, но соединение телефона с компьютером необходимо. Адреса определяются локально, без обращения к внешнему сервису.

## Самостоятельный запуск на телефоне и офлайн-режим

Для доступа без работающего компьютера разместите статические файлы игры из ZIP на хостинге с **HTTPS**: `index.html`, `styles.css`, `bootstrap.js`, `game.py`, `engine.py`, `content.py`, `scene.svg`, `manifest.webmanifest`, `sw.js`, папки `assets` и `vendor`. Сохраните имена и структуру папок. Сервер должен отдавать `.py` как обычные текстовые файлы, а не запускать их на сервере. Python, CMD и служебные документы на хостинг загружать не требуется.

Откройте HTTPS-адрес в Safari на iPhone или Chrome на Android. После первой полной загрузки добавьте игру на главный экран: в Safari через «Поделиться» → «На экран Домой», в Chrome через меню установки/добавления на главный экран. Названия пунктов могут зависеть от версии браузера. После сохранения ресурсов игра работает офлайн; браузер может удалять данные сайта при очистке или нехватке места.

Установка PWA и офлайн-кэш работают только в безопасном контексте **HTTPS или localhost**. Обычный HTTP-адрес компьютера в Wi-Fi подходит для игры, но не обеспечивает установку и офлайн-режим на телефоне. Публичный сайт не опубликован; нативные **APK и IPA не созданы**. ZIP содержит автономную HTML-игру, исходники и локальный сервер, а не приложение из магазина.

## Правила

- В смене **12 клиентов**, на каждого отведено **35 секунд**.
- Прочитайте просьбу клиента и выберите раздел терминала.
- Верный талон: **+1**. Неверный талон или истекшее время: **−1**.
- В тренировке таймера нет: можно спокойно изучать обращения и объяснения.
- Кнопка **«Пауза»** останавливает таймер. При переходе в другое окно или вкладку игра тоже ставится на паузу; вернувшись, нажмите **«Продолжить»**.
- На клавиатуре: **1–6** — выбрать раздел, **P** (русская **З**) — пауза/продолжение, **Enter** — начать смену или перейти к следующему клиенту. Если кнопка уже в фокусе, Enter нажимает её. На телефоне нажимайте экранные кнопки.

Категории и ситуации основаны на продуктах и услугах Сбера, Альфа-Банка и ВТБ. Названия разделов унифицированы для игры: это учебная модель, а не точная копия терминала конкретного отделения. Источники и пояснения — в `SOURCES.md`.

## Изменение сценариев

Сценарии обращений, категории и пояснения находятся в `content.py`; правила и подсчёт очков — в `engine.py`; интерфейс — в `game.py`, `styles.css` и `scene.svg`. Следуйте структуре существующих записей в `content.py`: у каждого обращения должен быть корректный идентификатор категории и понятное объяснение. Сохраняйте файлы в UTF-8.

После изменения исходников обновите страницу локального сервера. Для обновления автономного файла «Играть.html» снова запустите `build_release.py`. Если вы изменяете опубликованную офлайн-версию, также увеличьте версию кэша в `sw.js`, чтобы новые файлы заменили сохранённые.

## Проверка и сборка

Из папки исходников или полностью распакованного ZIP:

```powershell
py -3 -m unittest discover -s tests -v
py -3 build_release.py
```

Сборщик проверяет наличие всех игровых файлов и создаёт **`dist/Играть.html`** и **`dist/osm-game.zip`**. В архив входят автономная HTML-игра, исходники, локальный Brython с лицензией, оба запуска сервера для Windows, README, источники, сборщик и три файла тестов. Временные данные и прочее содержимое рабочего каталога не включаются. Локальный сервер раздаёт только явный список игровых файлов; каталоги, файлы запуска и тесты через HTTP недоступны.

Необязательная сборка EXE на Windows:

```powershell
py -3 build_release.py --exe
```

Она создаёт `dist/OSMGame.exe`, только если **PyInstaller уже установлен** в используемом Python. Скрипт ничего не устанавливает. EXE содержит Python и поэтому значительно больше HTML-файла; автономная HTML-версия — самый простой способ играть на Windows без установки Python. EXE не обязателен и в текущую поставку не входит.
